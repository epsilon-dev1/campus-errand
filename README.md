\# 校园跑腿任务调度系统



基于 C 语言实现的校园跑腿任务调度模拟系统，使用多种数据结构完成任务的排队、路径规划与统计。



\## 功能



\- 📋 发布跑腿任务（取快递、带饭、买药等）

\- 🔥 按紧急度和赏金自动排序任务（最大堆）

\- 🗺️ 基于校园地图计算最短路线（Dijkstra 算法）

\- 📊 统计已完成任务和总收入

\- 🎲 随机生成测试任务



\## 数据结构



| 数据结构 | 用途 |

|---------|------|

| 图（邻接矩阵） | 存储校园地点与道路 |

| Dijkstra 算法 | 计算最短路径 |

| 最大堆 | 按优先级排序任务 |

| 链表 | 记录已完成任务 |
